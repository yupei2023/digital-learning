M0 量规（自查用）M0 Rubric (for self-checking)

量规的三行就是本单元的三条目标。本单元不计分：在校学生的导师只在登记表上记“完成 / 未完成”；你自己用这张表看看第 2 周之前还缺什么。评级四级：达标 / 发展中 / 尚未达标 / 证据不足。

The three rows are the module's three objectives. This module is ungraded: mentors only mark enrolled students “done / not done” on the tracking sheet; use the table yourself to see what is still missing before Week 2. Four levels: Meets / Developing / Not yet / No evidence.
