## r5 新增决定 New decisions (2026-08-31)

34. **录屏的去留——判断与理由（B1 与 B2 同一条，两个 README 各存一份）**。ShiFu 的指令是"把截图、录屏内容移到第 2 周作为附件练习"。**截图与标注照办了；录屏没有跟过来，留在第 3 周。** 三条理由：
