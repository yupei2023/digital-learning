收紧渔网Narrow the net

微课 1 教你选词——那是决定网撒在哪片水域。本课的几个"限定词"（也叫搜索指令），是拉紧网口的绳子：告诉引擎"只要原句""只在这个网站找""只要这种文件"。它们不神秘，就是几个打在搜索框里的记号；主流搜索引擎（必应、百度等）大多认得，但支持程度各有脾气——所以先记住一句话：限定词是快捷键，不是魔法。哪个不灵，退回微课 1 的换词法就是。

Micro-lesson 1 taught word choice — that decides which waters the net covers. This lesson's operators are the drawstrings: they tell the engine "this exact phrase only", "this one site only", "this file type only". Nothing mystical — just a few marks typed into the box. The major engines (Bing, Baidu and friends) mostly honour them, each with its own temperament — so hold this sentence first: operators are shortcuts, not magic. When one is ignored, fall back to micro-lesson 1's word-swapping.

四根绳子Four drawstrings

限定词Operator它说的是What it says什么时候用When to use it
"…"
英文双引号straight double quotes		"这几个字，按原样连在一起出现。"例："聪明反被聪明误""These words, exactly, in this order." E.g. "a piece of cake"找歌词、诗句、名言、报错信息的原文。引号引短语最灵——整句长文塞进引号反而一无所获。Lyrics, verse, quotations, error messages verbatim. Quotes work best on phrases — an entire long sentence inside quotes starves the search.
site:"只在这个网站里找。"例：睡眠 site:edu.cn——只看教育机构域名下的页面。"Search inside this site only." E.g. sleep site:edu.cn — pages under educational domains only.你已经知道哪类网站靠谱、或想避开满街摊贩时。冒号后面紧跟网址，不加空格。When you already know which kind of site to trust, or want off the noisy street. The address follows the colon with no space.
filetype:"只要这种文件。"例：学习方法 filetype:pdf——只找 PDF 文档。"This file type only." E.g. study methods filetype:pdf — PDF documents only.找讲义、报告、官方文件。必应支持得稳；百度时好时坏——不认就在关键词后面直接加 pdf 两个词兜底。Handouts, reports, official documents. Bing honours it reliably; Baidu is moody — when ignored, just append pdf as a plain keyword instead.
时间筛选Time filter"只要最近的。"不打字——在结果页找"搜索工具 / 筛选"菜单，选"一年内""一月内"。"Recent pages only." No typing — open the results page's tools/filter menu and pick "past year" or "past month".查会过时的事（软件用法、健康建议、赛事）。十年前的"最新攻略"，标题可不会自己承认过时。手机上这个入口常藏在结果页顶部的"筛选"里；一时找不到就算了——回到换词法，不为一根绳子耗时间。Anything that ages: software how-tos, health advice, current events. A ten-year-old "latest guide" never confesses its age in the title. On phones the menu often hides behind a "filter" toggle at the top of the results page; if it refuses to appear, let it go — back to word-swapping, no time lost on one drawstring.
诚实的说明书The honest fine print
这些记号没有统一的国家标准，各引擎自己定支持范围，还会悄悄改。所以本课只教"值得一试"，不承诺"一定灵"。判断灵不灵的办法很简单：加了限定词，结果明显变少变准就是认了；毫无变化就是没认——换招，不纠结。No national standard governs these marks; each engine sets its own support and quietly changes it. Hence this lesson promises "worth trying", never "guaranteed". Telling whether one worked is simple: if results grow visibly fewer and sharper, it was honoured; if nothing changes, it wasn't — switch moves, no brooding.

组合拳：一个真实例子The combination: one real example

想找一份讲青少年睡眠的正式资料：先想词（青少年 睡眠 时长 建议）→ 结果太杂，收紧（青少年 睡眠 site:gov.cn）→ 想要能打印的，再收（加 filetype:pdf，或补一个关键词 指南）。每收一次，看一眼结果有没有变准——限定词一次加一根，才知道是哪根起了作用。Hunting an official document on teenage sleep: choose words first (teenager sleep duration recommendation) → too messy, tighten (teenager sleep site:gov.cn) → want it printable, tighten again (add filetype:pdf, or the plain keyword guidelines). After each pull, check whether the results sharpened — add one drawstring at a time, or you will never know which one worked.
