# M3 图片替代文字清单 Alt-text list

本单元页面上没有放置图片：所有"图"都是 HTML 表格或文字（四个原因表、SMART 五格表、模糊版 / 达标版对照、四种改法表），语言开关可以切换，屏幕阅读器可以直接读。学习者自己上传的日程截图在他们的网站上，本清单不管。
No images are placed in this module: every "figure" is an HTML table or text (the four-causes table, the SMART table, the fuzzy/SMART comparison, the four-changes table), so the language switch applies and screen readers read them directly. Learners' own schedule screenshots live on their sites and are outside this list.
