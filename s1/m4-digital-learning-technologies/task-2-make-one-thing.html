任务 2 · 用一件工具做一件小作品Task 2 · Make one small thing with one tool

三选一：导图 / 闪卡 / 短视频Pick one: map / cards / video中心来自主修课Centre from the core course约 22 分钟（首次会更久）~22 min (longer the first time)

要做什么What to do

用你在任务 1 里选定的那件工具，做一件小作品，发布到你网站的“作品集”页，标题“M4 任务 2 · 我的小作品”，附一两句“它帮我学了什么”。作品的中心必须是主修课里的一个概念或一组术语——就是你这两周本来要学的东西。

With the tool you chose in Task 1, make one small artifact and publish it on your Portfolio page as “M4 Task 2 · My small thing”, with one or two sentences on what it helped you learn. The centre must be one concept or one set of terms from your core course — the thing you had to learn these two weeks anyway.

硬性要求Hard requirements

  • 作品本身在网站上——图片能看见、视频能播放或能下载。只有“我做了”的截图或文字描述，按“尚未达标”计。The artifact itself is on the site — image visible, video playable or downloadable. A screenshot or description saying “I made it” rates Not yet.
  • 是你自己用工具做的。AI 只能帮改文字；整张导图 / 整组卡 / 整段脚本由 AI 生成的，不算本单元作品。Made by you with the tool. AI may only help with wording; a whole map / deck / script generated by AI does not count as this module's artifact.
  • 中心来自主修课；用的是任务 1 里选定的工具（换了要说明为什么）。The centre comes from the core course; the tool is the one chosen in Task 1 (if you switched, say why).
  • 隐私与版权：不露脸、不露全名；不用他人的图片、音乐、配音；屏幕上不出现邮箱、他人姓名、学校全名。Privacy and copyright: no face, no full name; no one else's images, music or voice; no email, others' names or full school name on screen.
  • 附一两句“它帮我学了什么”，指向一个具体的概念或发现；结尾附 AI 使用说明（或“本文未使用 AI”）。One or two sentences on what it helped you learn, naming a specific concept or discovery; end with an AI use note (or “No AI was used”).

常见问题FAQ

视频文件太大，网站传不上去。The video file is too big for my site.

两分钟的录屏通常在几十 MB 以内；超过了，先检查录制分辨率（720p 足够），或把时长压到 90 秒。仍传不上，放一个能打开的文件链接（网站自带的文件存储）也算发布。

A two-minute screen recording is usually a few dozen MB at most; if larger, check the recording resolution (720p is enough) or trim to 90 seconds. If it still won't upload, a working file link (your site's own file storage) counts as publishing.

XMind 免费版导出有水印。XMind's free export has a watermark.

允许。或者用截图代替导出；或者用 Freeplane / 幕布。不要为了去水印去注册账号——它要手机号。

That's fine. Or use a screenshot instead of export; or use Freeplane / 幕布. Don't create an account to remove it — it needs a phone number.

可以做两件吗？Can I make two?

本周只评一件；第二件是“想学更多”里的选做，寒假做也可以，作品集周可以一起放进去。

Only one is scored this week; a second is the optional item on the Want-more page — over the break is fine, and both can go into the portfolio.
