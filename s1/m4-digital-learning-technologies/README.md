核心问题 Essential questions（教纲 v7 W13–14 行 + 2021 校本教材第四模块改写）：
- 六类数字化学习工具各解决什么学习问题？What does each of the six tool categories do for a learner?
- 工具越多越好吗？——面对一个真实的学习任务，我怎样做出有理由的选择？Are more tools better? Given a real learning task, how do I choose — and say why?
- 我能用自己选的工具独立做出一件东西吗？Can I make something with the tool I chose?

**本单元的特别之处 What makes M4 different**：第一学期唯一"动手做东西"的单元。作品是一件用工具做出来的实物——思维导图、闪卡组，或 ≤ 2 分钟讲解短视频——而且必须服务于学习者自己正在学的主修外部课程（外部课程线 W11–14 每周 1 小时）。2021 版的"线上协作文档"任务按年计划 v2 的"个体学习者"约束取消，改为"用一件工具独立做一件小作品"。The one making module in Semester 1: the artifact is a thing made with a tool, in service of the learner's own core external course; the 2021 shared-doc collaboration task is replaced by an individual artifact.

单元目标（= 量规评分行）Module objectives (= rubric rows)：
① 说出六类数字化学习工具各自解决的学习问题，并为每一类举出一个自己能用到的免费工具例子；
② 围绕主修外部课程里的同一个真实学习任务，试用三类工具各一件，各写一则微评（做什么 · 好在哪 · 卡在哪 · 我会不会继续用），并说明最终选哪一件、为什么；
③ 用所选的那一件工具独立做出一件小作品（思维导图 / 闪卡组 / ≤ 2 分钟讲解短视频），发布到个人网站，并用一两句话说明它帮自己学了什么。

English parallel: ① Name the learning problem each of the six tool categories solves, and give one free tool you could actually use for each; ② For one real task from your core external course, try one tool from each of three categories and write a micro-review of each (what it does · what worked · what got stuck · would I keep using it), then say which one you chose and why; ③ Make one small artifact with the tool you chose (a mind map / a flashcard deck / a ≤ 2-minute explainer video), publish it on your own website, and add one or two sentences on what it helped you learn.

目标来源 Where these come from：蓝图 v6 §7 M4 三条目标与教纲 v7 CLO 4（"在六类数字化学习工具中做出有理由的选择，并用所选工具独立做出作品"）。改动三处：① 加"自己能用到的免费工具"，把"举例"从背名字变成选得着（工具规则：免费、只用邮箱、不用 VPN）；② 把"测评"落到"主修课里的同一个真实任务"，微评四栏是固定格式；③ 按年计划 v2 把"共享文档协作"整个替换为"独立做一件小作品 + 发布到个人网站"，作品三选一照抄年计划 W13–14 行，视频时长按预算方案 B 定为 ≤ 2 分钟。2021 校本教材第四模块另两条目标（检索、线上清晰表达）已由 B5 与 M2 覆盖，只在微课 1 里回访。

分值分配 Points：① 4（4·3·1·0）· ② 5（5·4·2·0）· ③ 6（6·4·2·0）= 15。两项计分任务：任务 1（W13 发布、W14 补第三则后评）= ① + ②（9 分）；任务 2（W14）= ③（6 分）。③ 分最高，因为"做出来并发布"是本单元真正的证据；② 次之，因为"有理由的选择"是 CLO 4 的核心动词；① 是知识层。
