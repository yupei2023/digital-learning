六类分类：这件工具在做什么？Sort the six: what is this tool doing?

十二张卡，每张是“一件工具 + 一种用法”。点一张卡，再点一个筐。其中三张是“看用法”卡——两个筐都对。全部放完、点“检查”之后，这三张卡下面会出现填空，请写出“当我用它____的时候，它就是这一类”（只保存在你自己的浏览器里）。每张卡都有解释——解释比对错更重要。

Twelve cards, each “one tool + one use”. Tap a card, then tap a bin. Three are “depends on use” cards — two bins are both right. When all twelve are placed, press Check: a blank then appears under each of the three, where you write “when I use it to ____, it is this category” (saved only in this browser). Every card has an explanation — the explanation matters more than the score.
