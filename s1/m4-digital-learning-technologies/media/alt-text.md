No image files are placed in this module: the only "figure" — the six-category map — is six HTML/CSS boxes (`lesson-1-six-categories.html`, `role="img"` with a bilingual `aria-label`), so the language switch applies and screen readers read it directly; every other "figure" is an HTML table. Learners' own screenshots and artifacts live on their sites and are outside this list.
