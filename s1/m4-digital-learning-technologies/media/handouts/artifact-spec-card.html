小作品规格卡（三选一）Artifact spec card (pick one)

三种都从同一步开始：中心 = 主修课里的一个概念或一组术语。规格故意很小，做到“能发布”就够了。

All three begin with the same step: the centre = one concept or one set of terms from the core course. The specs are deliberately small; “publishable” is enough.
