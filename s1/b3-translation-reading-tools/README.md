单元目标（= 量规评分行）Module objectives (= rubric rows)：
① 用翻译工具读完一段真实的英文课程介绍，并在自己的网站上发布"读后小报告"：一张截图（工具使用中，原文与译文同框，个人信息已打码）+ 三句话指出译文译错或走样之处 + 一句"这门课我想不想试，为什么"；链接登记到登记表（公开学习者：链接存进自己的邮箱）；
② 对介绍里的一个关键句完成"回译核对"，报告里写三行证据：原句 · 回译句 · 一处差异（没发现明显差异的，写明对照过程同样算完成）；
③（不计分 · 完成 ✓）练成"翻译工具包"跟做三幕：整段粘贴通读、回译核对一个句子、词典深挖两个单词（发音 + 例句）；成果留在学生自己设备上。

另有不进量规的知识点（两个局限、单词与整段的判断、朗读工具、不粘贴个人信息），由不计分的自测题显式承接——页面注明"自测题帮你检查，不计分"（沿 B1 r2 · 评估 J2 的口径）。

English parallel: ① Read a real English course intro with a tool and publish the reading report (framed screenshot + three specific sentences + one verdict), link registered; ② the back-translation check on one key sentence, its three evidence lines in the report (an honest "no clear difference, here is how I compared" counts in full); ③ (ungraded ✓) the translation-kit follow-along.

流水线规则：每个待批准项取推荐选项。每一条都可以推翻；推翻后改 `tools/b3/` 里的片段并重跑 `python3 tools/build_b3.py` 即可。

1. **三条目标与 3 + 2 分值**：见上。报告本体 3 分、回译核对 2 分——回译单列成行，因为它是本单元的核心习惯，且年计划"三句话指出译错之处"实际依赖它才做得出。
2. **第 ② 行不设半分档**（B1 模板说明明写半分档不要照抄）：2 · 1 · 0 · 0——"尚未达标"（报告在而无回译痕迹）与"证据不足"（没有报告）同 0 分不同措辞，量规与评分表按不同回应处理（沿 B2 决定 2 的做法）。
3. **"诚实核对同样满分"写进量规**：对照后没发现明显差异、如实写明过程 → ② 行满分。理由：任务评的是核对的诚实，不是"必须抓到错"；否则等于逼英语弱的学生编造错误、逼英语强的学生在译得好的段落上硬凑——两头都失真。此口径同时写进任务页 FAQ、量规、导师评分表与句式库。
4. **任务材料 = 外部课程菜单的真实英文介绍**（指令要求）：九门语言含英文的课任选。外部链接全部"待实测"，页面设两级兜底：打不开换一门 → 都打不开把菜单页切英文读菜单内介绍（并在报告注明）。两级同分。学生报告里的"打不开"课程名由导师周日汇总给教师——开课前实测的第一手数据（评分表新列）。
