One drawn figure exists in this module, an unbranded inline SVG wireframe (bilingual labels following the language switch; role="img" with bilingual alt text — first row below). Every other "figure" is an HTML table (the five tools, the three moments, the rubric, the time table, the handout card), so the language switch applies and screen readers read them directly. The practice English passages are data-neutral quote blocks, shown verbatim in both languages. Learners' own screenshots and reports live on their own devices and sites, outside this list.
