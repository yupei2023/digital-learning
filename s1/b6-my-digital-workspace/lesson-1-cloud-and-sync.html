云盘与多设备同步：文件的家Cloud & sync: the home of files

§0 那一分钟你已经亲身量过：文件散养的代价，是"找"。还有一个更隐蔽的代价叫"版本"——手机上改到一半的作文、电脑上还是昨天的旧稿，到底哪份是最新的？本课解决这两件事，答案是同一句话：给文件一个所有设备都看得到的家，"最新版"住在家里，不住在某台机器上。这个家通常叫云盘（网盘）——把文件存在网上的一块自己的空间里，手机改了，电脑打开就是改后的样子。

§0's minute measured it first-hand: the price of free-range files is the finding. A sneakier price is the version — the essay half-edited on the phone, yesterday's draft still on the computer; which one is newest? This lesson settles both with a single sentence: give your files one home every device can see, and let the latest version live in the home, not on any one machine. That home is usually a cloud drive — a space of your own on the internet, where a change made on the phone is what the computer opens.

诚实的选项表：三条路线，都免费The honest options: three routes, all free

三条路线在本周量规里同分：工作台评的是"东西找得到"，不评"用了哪家"。走了哪条，导览里如实说一句即可。另外两句实话：微信"文件传输助手"是个好快递员（设备间传一下很方便），但不是家——聊天记录会被清理，别把它当存放处；手机上传完文件想确认，去云盘 App 或网页端亲眼看一眼，比"应该传上了"可靠。All three routes score identically on this week's rubric: the workspace is judged on "things findable", never on brand. Whichever you take, one honest sentence in the tour suffices. Two more plain truths: WeChat's File Transfer is a fine courier (handy for tossing a file between devices) but no home — chat histories get cleared, so never let it be the storage; and after uploading from a phone, confirm with your own eyes in the drive's app or web page — "it probably uploaded" is not a system.

顺手一招：生成分享链接One handy move: the share link

下周（M1 任务 1）你可能要把一段录音或视频放上网站，而建站平台常常传不下这么大的文件。这时用分享链接：文件仍旧躺在你的云盘里，云盘另外给你一条网址，拿到网址的人就能打开它。各家做法几乎一样：选中那个文件 → 点"分享"→ 复制链接（有的会让你设有效期或提取码——设了就把提取码一并写在网页上，否则别人打不开）。把网址贴到网站上，配一句"点这里听录音"就完成了。没有云盘也不耽误：先试建站平台自带的上传（传得上去最省事），传不上去就把文件留在本地课程文件夹 / U 盘，网页上如实写一句"文件较大，导师可来信索取"——按 M1 的老规矩，别为了放一个文件去注册要手机号、又没有"仅链接可见"的视频网站。一句隐私提醒：分享链接等于把一把钥匙放在网上——只分享作业需要的那一个文件，别分享整个文件夹；链接和文件名里不出现真名与学校全名；能设有效期就设。Next week (M1's Task 1) you may need an audio or video clip on your site, and site builders often refuse a file that large. That is what a share link is for: the file stays in your cloud drive, the drive hands you a web address, and whoever holds the address can open it. The move is nearly the same everywhere: select the file → press Share → copy the link (some ask for an expiry date or an access code — set one, and write the code beside the link, or nobody gets in). Paste the address onto your site with a line like "click here to hear the recording", and it is done. No cloud drive, no problem: try the site builder's own upload first (simplest of all where it fits); where it will not fit, keep the file in your local course folder or on a USB stick and write an honest line on the page — "large file; mentors may write for a copy". By M1's standing rule, never register with a phone-number video site that has no unlisted mode just to host one file. One privacy note: a share link is a key left lying on the internet — share the single file the assignment needs, never a whole folder; keep real names and full school names out of both link and filename; and set an expiry date wherever the drive offers one.

备份：后悔药也住在这个角Backup: the regret cure lives in this corner too

第 3 周课程说明里埋过一句承诺："每次发布后自己保存一份备份（B6 会教你）。"现在兑现。规矩只有一条：每次点完"发布"，把这次的正文（和图）另存一份——存进云盘的"网站备份"文件夹，或当附件发给自己的邮箱，主题照命名规则（如"数字化学习-W7-工作台导览-化名"）。为什么值得：建站平台在别人的服务器上，它维护、改版、甚至有一天关停，都不由你——一份在平台，一份在自己手里，你才真正拥有自己写下的东西。一次备份不到两分钟；本周任务的最后一步，就是这个动作的第一次正式执行。Week 3's course guide planted a promise: "keep a backup after each publish (B6 teaches you how)." Here it is, honoured. The rule has one line: every time you press Publish, save this version's text (and images) once more — into a "site backups" folder on your drive, or as an attachment emailed to yourself, subject by the naming rule (say "DL-W7-workspace-tour-Chenxing"). Why it earns its keep: the site builder runs on someone else's servers, and its maintenance, redesigns, even its eventual closing are none of them yours to decide — one copy on the platform, one in your own hands, and only then do you truly own what you wrote. A backup takes under two minutes; the final step of this week's task is this very move's first official run.

一句要紧的分辨：同步不等于备份。同步是"两边保持一样"——你误删了一个文件，同步会忠实地把"删除"也传过去。所以重要的东西除了同步之外，还要有一份不会自动变的副本（发给邮箱的那份、U 盘里的那份，就是它）。One distinction worth its weight: sync is not backup. Sync means "keep both sides the same" — delete a file by mistake and sync will faithfully carry the deletion across. So the things that matter keep, beyond sync, one copy that never changes by itself (the one in your inbox, the one on the USB stick — that copy).

共用电脑的口径沿第 5 周：不在共用机器上常驻登录云盘客户端——用网页版，用完登出。文件夹命名沿第 5 周"用途-时间-内容"规则——云端的文件夹和本地的一样，配得上一个好名字。The shared-computer rule carries over from Week 5: no resident cloud-client sign-ins on a shared machine — use the web version and log out after. Folder naming follows Week 5's purpose-time-content rule — a folder in the cloud deserves a proper name exactly as a local one does.
