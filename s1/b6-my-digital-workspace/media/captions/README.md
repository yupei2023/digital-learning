# B6 字幕说明 Captions

本单元嵌入的 B 站视频均使用平台自带字幕（如上传者提供）或视频内置硬字幕；课程未另制字幕文件。
The embedded Bilibili clips rely on platform captions (where the uploader provides them) or burned-in subtitles; the course produces no separate caption files.

每段视频旁的文字说明（标题 · 时长 · UP 主 · 年份 · 一句内容简介）双语并列，视频不可用时页面文字版仍完整可学——B 周课程规范：每段微课都有文字版。
Each clip carries a bilingual caption line (title · duration · uploader · year · one-line summary), and every micro-lesson has a full text version, so the page teaches completely even when a clip fails.

若日后自录微课（脚本见 `scripts.md`），字幕文件（.srt，双语）存放于本文件夹。
If the micro-lessons are later self-recorded (scripts in `scripts.md`), the bilingual .srt files live in this folder.
