# B4 字幕 Captions

本文件夹为日后自录微课预留。若录制，每段导出中英两份 `.srt`，命名：
`lesson-1.zh.srt` / `lesson-1.en.srt` … `lesson-4.zh.srt` / `lesson-4.en.srt`。

目前 B4 嵌入的是公开 B 站视频（见 `../scripts.md` 来源表），字幕以各视频自带为准；四段微课均有完整双语文字版页面，屏幕阅读器可直接读。
This folder is reserved for future self-recorded lessons (bilingual .srt per clip, named as above). The currently embedded Bilibili clips carry whatever captions their uploaders provide; every micro-lesson has a full bilingual text page.
