核心问题 Essential questions（教纲 v7 W15–16 行）：
- 这一学期，我作为数字化学习者有何成长？How have I grown as a digital learner this semester?
- 哪几件作品能证明——为什么是它们？Which works are the evidence, and why those?
- 对照第 2 周的自己，下学期我要去哪里？Set beside my Week-2 self, where next?

**本单元的特别之处 What makes M5 different**：第一学期的总结性收尾。不学新知识——学习者自己的网站就是教材。两件事：把十六周的作品挑成一本"学期作品集 v1"（挑选 = 又一次"选择的本质是放弃"，回访 M4 读本）；对照第 2 周的学习状态自测基线写学期反思（🚫 独立——反思是一面镜子，评投入与形式，不评成长大小）。作品集与反思共用**全课程唯一的收尾日**（只指向当年"本学期日历"页，页面不写日期）。The semester's summative close: nothing new is taught — the learner's own site is the textbook. Curate 16 weeks into Portfolio v1; write the reflection against the Week-2 baseline. The two share the course's only firm closing date (pages point to the per-year calendar page, never a date).

单元目标（= 量规评分行）Module objectives (= rubric rows)：
① 在个人网站的"作品集"页建成"学期作品集 v1"：遴选 5–7 件最能代表这学期成长的作品（覆盖至少三个不同单元，并含"外部课程进度 + 一件相关作品"一条），每件配可打开的链接或作品本身；
② 为每件入选作品写一则三句成长说明（当时做了什么、卡在哪 · 现在再看有什么变化 · 它证明我学会了什么）；M4 小作品那一条还要回答：做完之后用过它吗？寒假第一次学主修课时打算怎么用？
③ 复测"学习状态自测"，对照第 2 周的基线，独立写一篇 300–500 字的学期反思：变化最大的一项及其作品证据、没变（或变低）的一项、下学期的两件具体打算。

English parallel: ① Build "Semester Portfolio v1" on your Portfolio page: 5–7 works that best show this semester's growth (≥ 3 modules; one entry of "external-course progress + one related work"), each with a working link or the work itself; ② Write a three-sentence growth note per work (then · now · proof); the M4 artifact's note also answers "used since / how over the break"; ③ Retake the learning self-check, set it beside the Week-2 baseline, and independently write a 300–500-character/word reflection: biggest change with portfolio evidence, one thing that didn't move (or dropped), two concrete plans.

目标来源 Where these come from：教纲 v7 W15–16 行（遴选 5–7 件并写成长说明 ✅；复测自测并对照基线反思 🚫；匿名问卷）+ 年计划 v2.1 §2 W15–16 行（作品集 v1 默认仅链接可见；2 分钟工具推荐选做）+ CLO 8（汇集证据、反思成长、规划后续）+ 外部课程线 v2 触点 5（进度 + 一件作品）+ M4 评估遗留 J4（作品"用一次"回访写入 M5）。
