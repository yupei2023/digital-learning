做Do

  • 录 2 分钟“我最推荐的一个学习工具”——四句结构见微课 4。发布到网站，作品集里加一条也行。Record the 2-minute “one tool I'd recommend” — the four-sentence structure is in micro-lesson 4. Publish it; it may even join the portfolio.
  • 做 M4 的第二件作品——同一个中心，换一种输出（做过导图的做闪卡，做过闪卡的录视频），比一比哪种让你发现更多“原来没懂”。作品集 v2 候选。Make M4's second artifact — same centre, the other output (cards if you mapped, video if you carded); compare which exposes more of what you hadn't understood. A v2 candidate.
  • 给作品集画一张封面——自己画、自己拍或用形状拼一张（不用别人的图片），放在“学期作品集 v1”标题上方。明年一月打开时，它是第一眼。Make the portfolio a cover image — drawn, photographed or built from shapes yourself (no one else's pictures), placed above the v1 heading. It is the first thing January-you sees.
  • 寒假外部课程的一行日志——想继续主修课的话，每学一次记一行（学了什么 · 卡在哪 · 下次干什么）。不计分；开学第 1 周的“进度汇报”会用到。The break's one-line log — if you continue the core course, keep one line per session (what · stuck where · next). Ungraded; Week 1's progress report will thank you.
