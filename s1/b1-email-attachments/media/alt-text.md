# B1 图片替代文字清单 Alt-text list

本单元页面上没有放置图片文件：所有"图"都是 HTML 表格（六个部位表、三个框表、量规、时间表、讲义模板）或页内交互（分箱卡片、学习状态自测样题），语言开关可以切换，屏幕阅读器可以直接读。学习者自己的附件与截图在他们自己的设备上，本清单不管。
No image files are placed in this module: every "figure" is an HTML table (the six parts, the three boxes, the rubric, the time table, the handout template) or an in-page interaction (the sorting cards, the self-check samples), so the language switch applies and screen readers read them directly. Learners' own attachments live on their own devices and are outside this list.
