This module carries one historical photograph and four drawn figures (r5: the ask-with-a-screenshot figure arrives from B2). The photograph is on the module home (China's first email, 1987, an archive photograph — first row below). The drawn ones are inline SVG (unbranded, bilingual labels following the language switch, role="img" and a bilingual <title> on the svg): the six-part compose-window wireframe in micro-lesson 1 (redrawn; it replaces the earlier version, and micro-lesson 2 no longer repeats it but links back), the mentor's-Downloads-folder file list in micro-lesson 2, and the three-emails ladder on the Week 2 page. Every other "figure" is an HTML table (the six parts, the three boxes, the rubric, the time table, the handout template) or an in-page interaction (the sorting cards, the self-check samples), so the language switch applies and screen readers read them directly. Learners' own attachments live on their own devices and are outside this list.
